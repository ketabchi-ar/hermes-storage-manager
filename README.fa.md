## 🌟 چرا به Hermes Storage Optimizer نیاز دارید؟

هنگام کار مداوم با **Hermes Agent**، صدها مگابایت یا گیگابایت لاگ‌های حجیم، کش‌ها و نشست‌های گفتگوی بسیار سنگین در مسیر `~/.hermes` انباشته می‌شوند. این موضوع مشکلات زیر را ایجاد می‌کند:
1. **کند شدن شدید لود اولیه WebUI:** بارگذاری ده‌ها سشن چند ده مگابایتی و گیگابایتی سرعت رابط کاربری را کاهش می‌دهد.
2. **افزایش سرسام‌آور مصرف توکن و زمان تولید پاسخ:** سشن‌های بسیار طولانی باعث ارسال تاریخچه بزرگ به کانتکست مدل و اتلاف هزینه توکن می‌شوند.
3. **اشغال بیهوده هارد دیسک:** فایل‌های لاگ سرریز شده (`webui.log`)، فایل‌های کش صوتی موقت و دیتابیس بدون Vacuum تا چندین گیگابایت فضا مصرف می‌کنند.

**Hermes Storage Optimizer** یک ابزار مستقل، سریع و بدون نیاز به نصب هیچ‌گونه کتابخانه جانبی است که برای حل کامل این مسئله طراحی شده است.

## 🛡️ قابلیت‌های کلیدی

### ۱. 📊 نمودار بصری توزیع فضای ذخیره‌سازی
نمایش گرافیکی و رنگی سهم سشن‌های چت، محیط مجازی (venv)، دیتابیس وضعیت، فایل‌های لاگ، کش موقت و پوشه ضمیمه‌ها به صورت زنده.

### ۲. 🛠️ اقدامات نگهداری فوری (کاملاً امن و بدون از دست رفتن چت‌ها)
روی هر یک از دکمه‌ها حجم دقیق قابل آزادسازی به همراه یک آیکون راهنما (**ⓘ**) قرار گرفته است:
* **🧹 تخلیه لاگ‌های حجیم:** سبک کردن فایل‌های `webui.log` و `logs/*.log` و رساندن حجم آن‌ها به صفر بایت بدون ایجاد اختلال در سرور.
* **🗑️ پاکسازی کش موقت:** خالی کردن فایل‌های موقت صوتی (Whisper) و بافرهای موقت.
* **🗜️ فشرده‌سازی دیتابیس (Vacuum):** اجرای دستور استاندارد SQLite VACUUM روی `state.db` و بازگرداندن صفحات خالی دیتابیس به هارد دیسک.
* **📁 حذف ضمیمه‌های یتیم (Orphaned Assets):** شناسایی و حذف خودکار تصاویر و فایل‌های آپلودی که سشن مربوطه‌شان قبلاً حذف شده است.

### ۳. 💬 مدیریت سشن‌های سنگین و فوق سنگین
* فیلتر سشن‌ها بر اساس حجم (۵ مگابایت، ۲۰ مگابایت و ۱۰۰+ مگابایت).
* نمایش تفکیک‌شده تعداد پیام‌های ارسالی کاربر و پاسخ‌های هوش مصنوعی.
* **تخمین هوشمند کانتکست توکن:** نمایش تقریبی توکن مصرفی هر چت (`~k tokens`).
* **تاریخ‌های شمسی:** نمایش کامل تاریخ و ساعت آخرین ویرایش با تقویم خورشیدی در زبان فارسی.
* **مشاهده در WebUI با یک کلیک:** دکمه `↗️` جهت باز کردن مستقیم همان چت در پنل وب هرمس قبل از تصمیم‌گیری برای حذف.
* **پشتیبان‌گیری و آرشیو (ZIP):** امکان دانلود نشست به همراه کلیه تصاویر و فایل‌های ضمیمه‌اش در یک فایل زیپ قبل از حذف.

## ⚡ نحوه اجرا و استفاده

### روش اول: اجرای ویزارد وب (پیشنهادی)
بدون نیاز به نصب هیچ پیش‌نیازی، دستور زیر را در ترمینال اجرا کنید:
```bash
python3 main.py --ui
```
صفحه وب به صورت خودکار در مرورگر شما در آدرس `http://127.0.0.1:9123` باز می‌شود.

### روش دوم: بررسی سریع در محیط خط فرمان (CLI)
```bash
python3 main.py
```

### روش سوم: پاکسازی خودکار با فلگ‌های مستقیم
```bash
# تخلیه لاگ‌ها
python3 main.py --clean-logs

# پاکسازی کش موقت
python3 main.py --clean-cache

# فشرده‌سازی دیتابیس SQLite
python3 main.py --vacuum

# حذف ضمیمه‌های یتیم
python3 main.py --clean-orphaned
```
